Folder Structure and Dataset Paths

1. Ultrasound Fetus Dataset

* Folder: ./Ultrasound Fetus Dataset
* Train: ./Ultrasound Fetus Dataset/train
* Test: ./Ultrasound Fetus Dataset/test
* Notebook: main.ipynb
* Download: [https://data.mendeley.com/datasets/yrzzw9m6kk/1](https://data.mendeley.com/datasets/yrzzw9m6kk/1)

2. UC Merced Land Use Dataset

* Folder: ./UCMerced_LandUse
* Images: ./UCMerced_LandUse/Images
* Notebook: main.ipynb
* Download: [https://www.kaggle.com/datasets/abdulhasibuddin/uc-merced-land-use-dataset](https://www.kaggle.com/datasets/abdulhasibuddin/uc-merced-land-use-dataset)

3. AID Scene Classification Dataset

* Folder: ./AID
* Train: ./AID
* Notebook: main.ipynb
* Download: [https://www.kaggle.com/datasets/jiayuanchengala/aid-scene-classification-datasets](https://www.kaggle.com/datasets/jiayuanchengala/aid-scene-classification-datasets)

Instructions

1. Install dependencies:
   pip install torch torchvision scikit-learn matplotlib numpy
2. Download datasets and place them in the respective folders.
3. Run the corresponding notebook inside the dataset folder.
4. Outputs: Feature/label .npy files, best WOA parameters (.txt), plots, and evaluation metrics will be generated in the same folder.
5. The features/labels and parameters from previous training instances have also been included
